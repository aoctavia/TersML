# Machine Learning for Tip-Enhanced Raman Spectroscopy  
### Interpreting TERS Maps of π-Conjugated Molecules

---

## 🔬 Introduction
Tip-Enhanced Raman Spectroscopy (TERS) provides chemical imaging at atomic resolution, enabling direct access to vibrational and electronic properties of molecules on surfaces. However, interpreting TERS maps remains challenging due to:
- Complex vibrational spectra (mode mixing, broadening, probe effects).
- Sensitivity to local environment (substrates, strain, defects).
- The need for expensive first-principles simulations (DFT/TDDFT).

This project explores **machine learning (ML)** as a complementary tool for automated interpretation of TERS spectra and images, with a focus on **π-conjugated molecular systems** (benzene, naphthalene, graphene nanoflakes).  
Our aim is to bridge **spectroscopy and AI**, in line with recent advances in nanoscale quantum materials research.

---

## 📂 Dataset
- **Molecules:** benzene, naphthalene, anthracene, small graphene flakes.  
- **Vibrational data:** simulated from *ab initio* sources (QM9 / DFT calculations).  
- **TERS-like spectra:** generated by applying Gaussian broadening + local enhancement factors.  
- **TERS images:** created by spatially modulating intensities to mimic scanning probe signals.

Dataset examples are provided in `data/` and generated using `src/dataset.py`.

---

## ⚙️ Methods
We implement two complementary ML pipelines:

1. **Spectral Fingerprints (1D)**  
   - Input: synthetic Raman spectra (1D signals).  
   - Model: Convolutional Neural Network (CNN).  
   - Task: molecular classification, vibrational mode regression.  

2. **TERS Imaging (2D)**  
   - Input: simulated TERS maps (2D intensity images).  
   - Model: Vision Transformer (ViT) or ResNet.  
   - Task: automated molecular recognition from TERS images.  

**Physics-Informed Loss:**  
- Includes a penalty for violating Raman tensor symmetry constraints.  
- Encourages ML predictions to remain consistent with spectroscopy theory.
